# Upstream proposal

[IR declaration lookup](cards/ULC-0001-ir-declaration-lookup-boundary/README.md)
proposes an explicit provider API for Lean's interpreter. The comparison with
a real `Lean.Environment` explains why VIR currently uses a local provider.
The proposal is not implemented upstream and has no linked upstream issue.

For current VIR behavior, see the [documentation index](../README.md).
